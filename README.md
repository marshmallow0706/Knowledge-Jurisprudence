# 法学入門・体系教材(研究者のための法律基礎)

## この教材について

大学で法学を学んだことがない方が、研究・業務で必要になる法律知識を**体系的に**身につけるための教材です。法学の「考え方」→「法の仕組み」→「主要な法分野」→「研究に直結する法分野」→「調べ方」の順に進みます。

- **対象とする法**: 日本法(現行法)。国際法・EU法・比較法は第14章で扱います。
- **想定読者**: 法学の予備知識なし。大学の教養課程〜法学部1・2年生レベルを目安にしています。
- **注意**: 本教材は学習用であり、個別事案についての法的助言ではありません。法改正が頻繁にあるため、条文・施行日は必ず [e-Gov法令検索](https://laws.e-gov.go.jp/) などの一次情報で最新のものを確認してください(確認方法は第15章)。
- **記載の基準**: 内容は2026年10月時点の理解に基づきます。直近の改正・施行状況は一次情報で再確認してください。

## 推奨される学習ルート

1. **まず通読(約1〜2週間)**: 第1〜3章 → 第4章(憲法) → 第7〜8章(民法)。この5章が法学全体の土台です。
2. **必要に応じて拡張**: 自分の研究テーマに近い章を選びます。
   - 人を対象とする研究・データ利用 → 第13章 → 第4章(人権)
   - 技術開発・論文・共同研究 → 第12章 → 第8章(契約)
   - 雇用・研究室運営 → 第11章 → 第7章
   - 海外との連携 → 第14章
3. **実務で使う**: 第15章で、実際の条文と判例を自分で調べる練習をします。

## 各章の構成

各章は「①この章で学ぶこと → ②本文 → ③ポイントのまとめ → ④確認問題 → ⑤さらに学ぶために」の順です。確認問題は、答えを書き出してから本文に戻ると定着します。
